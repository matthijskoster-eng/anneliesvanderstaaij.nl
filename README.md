# anneliesvanderstaaij.nl

Personal website of Annelies van der Staaij. Plain static HTML/CSS, no build step, published with Cloudflare Pages.

- `index.html`: English (default)
- `nl/index.html`: Dutch, reached through the EN/NL switch in the header
- `assets/`: stylesheet, images, share image
- `_headers`, `404.html`, `robots.txt`, `sitemap.xml`: picked up by Cloudflare Pages

When editing text, change both language versions.

## Cloudflare Pages

Workers & Pages, Create, Pages, Connect to Git, pick this repository. Framework preset: None. Build command: empty. Build output directory: `/`. Every push to `main` goes live; every pull request gets a preview link.
